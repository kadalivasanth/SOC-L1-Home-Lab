# SOC-L1-Home-Lab
SOC L1 Home Lab

Project Overview

This project documents my hands-on learning in Security Operations Center (SOC) analysis, SIEM monitoring, Windows security logging, and incident investigation.

Objectives

* Understand Windows security logs and Sysmon events.
* Practise security event analysis using Splunk.
* Develop basic detection searches.
* Investigate alerts and document findings.
* Learn incident triage and reporting.

Tools

* Splunk
* Windows Event Viewer
* Sysmon
* Windows operating system

Project Status

In progress — configurations, detection searches, and investigation evidence will be added as each lab is completed.

Folder Structure

* splunk-searches/ — SIEM searches and detection logic.
* sysmon-config/ — Sysmon configuration notes.
* incident-reports/ — Security investigation reports.
* screenshots/ — Evidence from completed lab activities.

Disclaimer

All testing will be performed on systems and data I own or am authorized to use.
